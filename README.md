# Globe Deconstruction — review project

A claim-by-claim critical review of *Globe Deconstruction?*, a ~500-page self-described
"geocentrist" (not flat-earther) prerelease book by Levi Miller (with Alex Kampf and Mark
Meyer), argued against heliocentrism/the globe model. Companion project to
[flat-earth-origins](https://funwithscience.net/flat-earth-origins/), same reviewer
conventions: refute the source directly (not a summary of it), six-verdict rubric,
public-sourcing standard.

## Structure

- **`docs/`** — finished, publish-ready pages, served via GitHub Pages.
  - `docs/rampion/` — "The Black Swan, Answered": a point-by-point rebuttal of the
    Rampion Wind Farm / Worthing Beach curvature video the book cites (pp.91-95) as
    real-world evidence. `index.html` uses external image assets (`assets/`); a
    self-contained single-file copy with embedded images lives alongside it as
    `self-contained-preview.html`.
  - `docs/self-test-protocol/` — seven falsifiable tests Miller can run himself, built
    from his own stated methodology (falsification-first, Team A vs Team B). Hand-off-
    ready, no internal commentary.
- **`notes/`** — internal working material, not yet publish-ready.
  - `globe_deconstruction_session_notes.md` — running session log; **read this first** in
    any fresh session working on this project.
  - `globe_deconstruction_organized.md` — full claim-by-claim breakdown of the book,
    tagged ORIGINAL / RECYCLED / UNCLEAR against the flat-earth-origins argument-cluster
    catalogue.
  - `globe_deconstruction_summary.md` — concise summary of the book's main theses.
  - `globe_deconstruction_prerelease_text.txt` — raw `pdftotext -layout` extraction of the
    source PDF (500pp Canva export).
  - `Black_Swan_transcript_summary_fact_check.docx` — full cleaned transcript of the
    Rampion/"Black Swan" video plus a standalone scientific fact-check.
  - `working-review.html` — internal claim tracker (dark UI, ORIGINAL/RECYCLED/UNCLEAR
    tags, open items) — not meant for public consumption as-is.

## Status

No rebuttals/verdicts have been formally run through the six-verdict rubric yet except the
Rampion/Black Swan page, which was built ahead of the broader pass because a concrete
source video was available to answer directly. See `notes/globe_deconstruction_session_notes.md`
for the full history and open items.
